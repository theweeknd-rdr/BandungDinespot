# BandungDinespot 🍽️

Proyek open source untuk menemukan dan berbagi informasi tentang tempat makan di Bandung.

An open source project for discovering and sharing information about dining spots in Bandung.

## 📋 Tentang Proyek / About Project

BandungDinespot adalah platform yang bertujuan untuk membantu orang menemukan tempat makan terbaik di Bandung. Proyek ini dibuat sebagai tugas kampus dan sekarang dibuka untuk kontribusi dari siapa saja.

BandungDinespot is a platform that aims to help people find the best dining spots in Bandung. This project was created as a campus assignment and is now open for contributions from everyone.
