# Contributing to BandungDinespot

Terima kasih telah tertarik untuk berkontribusi pada BandungDinespot! Kami menyambut kontribusi dari siapa saja.

Thank you for your interest in contributing to BandungDinespot! We welcome contributions from everyone.

## Cara Berkontribusi / How to Contribute

### 1. Fork Repository
Fork repository ini ke akun GitHub Anda sendiri.

### 2. Clone Repository
```bash
git clone https://github.com/your-username/BandungDinespot.git
cd BandungDinespot
```

### 3. Buat Branch Baru / Create a New Branch
```bash
git checkout -b feature/nama-fitur-anda
```

### 4. Lakukan Perubahan / Make Your Changes
- Tulis kode yang bersih dan mudah dipahami
- Ikuti konvensi kode yang ada
- Tambahkan komentar jika diperlukan

### 5. Commit Perubahan / Commit Your Changes
```bash
git add .
git commit -m "Deskripsi singkat perubahan Anda"
```

### 6. Push ke GitHub / Push to GitHub
```bash
git push origin feature/nama-fitur-anda
```

### 7. Buat Pull Request
Buka Pull Request dari branch Anda ke branch `main` repository ini.

## Panduan Kode / Code Guidelines

- Gunakan nama variabel yang deskriptif
- Tulis komentar untuk logika yang kompleks
- Pastikan kode Anda berfungsi sebelum submit

## Pelaporan Bug / Bug Reports

Jika Anda menemukan bug, silakan buat issue baru dengan:
- Deskripsi jelas tentang bug
- Langkah-langkah untuk mereproduksi
- Hasil yang diharapkan vs hasil aktual
- Screenshot jika memungkinkan

## Pertanyaan / Questions

Jika Anda memiliki pertanyaan, silakan buat issue dengan label "question".

Terima kasih atas kontribusi Anda! / Thank you for your contributions!
